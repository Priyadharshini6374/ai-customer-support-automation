# AI-Powered Customer Support Automation

An AI-powered customer support automation workflow built using n8n, Groq LLM and Gmail.

## 🚀 Workflow

Customer Email
→ Gmail Trigger
→ AI Query Classification
→ AI Response Generation
→ Gmail
→ Customer Reply

## 🛠️ Technologies Used

- n8n
- Groq API
- LLM
- Gmail
- Prompt Engineering
- Workflow Automation

## ✨ Features

- Automatically receives customer emails
- Classifies queries into:
  - Payment
  - Refund
  - Technical
  - Account
  - Other
- Generates AI-powered customer responses
- Automatically sends the response through Gmail

## 🤖 AI Model

OpenAI GPT-OSS 20B through Groq

## 📌 Example

Customer:

"My payment failed. What should I do?"

AI Classification:

"Payment"

AI Response:

The workflow generates a polite and helpful customer-support response automatically.

## ⚠️ Security

API keys, Gmail credentials and other sensitive information are not included in this repository.
